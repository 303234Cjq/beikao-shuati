# 备考刷题站 · 数学二 / 811 电路 / 时政

在线地址：**https://303234cjq.github.io/beikao-shuati/**

单文件静态刷题页（`index.html`，1.7 MB，题库内嵌）。打开即用，手机浏览器也可以；建议在 Safari/Chrome 里"添加到主屏幕"，用起来跟 app 一样。

## 内容

- 1000 道练习 + 456 道历年真题（1990–2024）+ 88 道生成练习，按模块（极限、导数、积分、线代…）和年份筛选
- 数学公式由 MathJax 渲染（首次打开需要能访问 `cdn.jsdelivr.net`）
- 支持夜间模式、字号调节、必背公式栏、统计与预测

## 与云端版的区别

这份是**本地副本**，原本的云同步接口（`/__sync/*`、`/__live/version`）在静态托管下不存在，页面会提示"网络未连接 · 暂存本机"：

- 做题记录保存在**当前浏览器**的 localStorage 里，换设备或清浏览器数据就会丢失
- 需要跨设备同步时，去原云端站点 <https://fjut-study-desk.niftyolive256.chatgpt.site>，在那边点"云端已保存"再清理浏览器数据

## 更新

直接把新版 HTML 覆盖 `index.html` 后 `git push`，约 30 秒后生效。
